How to save

Keep the page you are on, from any browser.

  1. Copy the Save code.

  2. Tap Share, then Add Bookmark. Name it Save, put it in Favorites.

  3. Open bookmarks, hold Save, tap Edit. Paste the code as its address.

  4. On a page you want to keep: bookmarks, Save.

Black page, or Not Secure?iCloud Private Relay with Tailscale

Save runs inside the page you are on, and with Private Relay on that page goes through Apple. Apple cannot reach your Tailscale address, so Safari falls back to http and the page stays black. Let Tailscale find the address on your iPhone instead.

  1. In the Tailscale admin, under Machines, copy your iPhone's address. It starts with 100.
  2. Under Access controls, paste this right after the first { and put your iPhone's address in it. Save. 
    "nodeAttrs": [
  { "target": ["100.x.y.z"], "attr": ["disable-split-dns-when-no-custom-resolvers"] }
],
  3. On the iPhone, turn Tailscale off and on again.
