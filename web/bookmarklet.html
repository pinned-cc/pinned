Pinned

Save button

Saves the page you are on to Pinned, from any browser.

Mac

Show the bookmarks bar, then drag this button into it.

Save to Pinned

Brave and Chrome: Cmd Shift B. Safari: View, Show Favorites Bar.

iPhone

  1. In Safari, bookmark any page.
  2. Edit that bookmark, name it Save, and paste this code as its address.
  3. On a page you want to keep, open your bookmarks and tap Save.

Android

Open Pinned in Chrome and add it to the home screen. Then use Share on any page and pick Pinned.

Browser extension

Download the extension

  1. Unzip it.
  2. Brave, Chrome, Edge: open the extensions page, turn on developer mode, choose Load unpacked and pick the folder.
  3. Firefox: open about:debugging, choose This Firefox, then Load temporary add-on and pick manifest.json.
  4. Open the extension's options and enter your address and a token.
